# Recording Checklist

Primary recording file: `video_demo/recording_deck.html`

## Setup

1. Open the file in Chrome or Edge.
2. Set browser zoom to 100%.
3. Press F11 for fullscreen.
4. Use Space or the right arrow to advance one slide at a time.
5. Record the browser window at 1920x1080 if possible.

## Suggested Timing

- Slides 1-2: problem and motivation, 20-30 seconds.
- Slides 3-4: data structure and few-shot episode, 35-45 seconds.
- Slides 5-6: U-Net and Reptile, 35-45 seconds.
- Slides 7-9: results and report takeaway, 45-55 seconds.
- Slides 10-11: conference-paper 3D extension, 20-30 seconds.

## Talk-Over Emphasis

- The original project is 2D few-shot segmentation.
- The main evidence is not only that Reptile wins, but that success is structure-dependent.
- Task_8 is the limitation slide: small/sparse/variable targets remain hard.
- The final 3D section is a preview of later group extension work, not part of the original evaluation.
