Problem

Manual labels are the bottleneck

Medical segmentation needs expert annotation.
New structures rarely arrive with large labelled datasets.
Few-shot learning asks: can we adapt from only a handful of examples?

Data Structure

Tasks stay separated to prevent structure leakage

Talk over:Train, validation, and test are split by task. Within a task, support slices adapt the model and query slices measure Dice.

Episode Construction

Support teaches; query tests

Sample n labelled support slices.
Hold back the remaining slices as query data.
Use the same protocol for Reptile and baseline.

Model

Same U-Net, different starting point

Compact encoder-decoder U-Net.
GroupNorm stabilizes small batches.
BCE + Dice loss handles sparse foreground masks.

Meta-Learning

Reptile learns weights that adapt quickly

Sample a training task.
Clone the model and run a short inner loop.
Move the meta-weights toward the adapted weights.

Qualitative Result

5-shot predictions on held-out structures

Point out:Task_1 is spatially coherent; task_8 remains difficult because the target is small and sparse.

Quantitative Result

Reptile wins, but structure difficulty dominates

Task_1: Reptile mean DSC 0.369 vs baseline 0.259.
Task_8: near-zero for both methods.
More shots did not guarantee better results within 30 adaptation steps.

Paper Takeaway

Meta-learning helps, but cannot invent missing signal

"Support set size and adaptation budget must be considered jointly rather than in isolation."

task size shape variability foreground sparsity adaptation budget
Reptile provides a better initialization in low-data settings.
The hard case shows why anatomy-specific structure matters.
